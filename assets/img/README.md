# 画像の置き場所

ここに **ChenMe のブランド素材5枚** を、下の**ファイル名のとおり**に置いてください。
（ページ側のコードは一切さわらなくて大丈夫です）

| ファイル名 | 使う場所 | おすすめの形 |
|---|---|---|
| `logo.png` | ヘッダー／フッターのロゴ | 背景透過PNG・横長 |
| `product-hero.jpg` | ファーストビューの商品ボトル | 縦4:5・背景が明るいもの |
| `brand-01.jpg` | ブランドセクションの大きい写真 | 縦4:5 |
| `brand-02.jpg` | 下段2枚組の左 | 縦4:5 |
| `brand-03.jpg` | 下段2枚組の右 | 縦4:5 |

- 商品ボトルの写真は **加工・描き直しをせず、実物の撮影画像をそのまま**使ってください。
- 画像がまだ無い状態でもページは壊れません（やわらかいピンクの面が表示されます）。

## WebP（軽量版）の作り方

置いたあと、プロジェクト直下で次を実行すると `.webp` が自動生成されます。
スマホでの読み込みがかなり軽くなるので、公開前に必ず一度実行してください。

```bash
npm run images
```

`.webp` が無い場合は元の `.jpg` / `.png` が表示されるので、実行しなくても動きます。
