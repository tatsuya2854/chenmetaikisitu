# 画像について

## 現在入っているファイル（配置済み）

| ファイル名 | 中身 | サイズ | 使う場所 |
|---|---|---|---|
| `logo.png` | ChenMe ワードマーク（背景透過） | 720×183 | ヘッダー／フッター |
| `product-hero.jpg` / `.webp` | 寝室カット（ボトル） | 1080×1350 (4:5) | ファーストビュー |
| `brand-01.jpg` / `.webp` | モデルカット「今日より明日 もっとスッキリ」 | 1280×1280 (1:1) | ブランドセクション上 |
| `brand-02.jpg` / `.webp` | ボトル単体（ピンク背景・クリーム） | 1080×1440 (3:4) | ブランドセクション下 |

`_source/` には**加工前の原本**が入っています。ページからは参照していません。
トリミングをやり直したいときはここから作り直してください。

## 加工内容（商品そのものには一切手を加えていません）

- **`logo.png`** … 元のロゴ画像は淡いピンクの正方形背景つきだったため、
  **文字の外接矩形で切り抜き → 背景だけを透過** にしました。
  文字色は元画像の実測値 `rgb(106, 102, 99)` をそのまま使用し、
  字形・太さ・字間は一切変えていません（描き直しはしていません）。
- **`brand-02.jpg`** … 縦長（1449×2576）だったため、ボトルを中心に **3:4 でトリミング**。
- **`product-hero.jpg` / `brand-01.jpg`** … 元の比率のままリサイズのみ。
- **色調補正・レタッチ・ラベルやイラストの加工は一切していません。**

> 2枚目と3枚目に頂いた寝室カットは md5 が完全一致の同一ファイルでした。
> そのため実際に使用しているのは「ロゴ＋写真3枚」です。

## 差し替えかた

同じファイル名で上書きして、プロジェクト直下で次を実行するだけです。

```bash
npm install     # 初回だけ
npm run images  # .webp を再生成
```

`logo.png` は透過PNGのまま使うので変換対象外です。
`.webp` が無くても `.jpg` にフォールバックするので、ページが壊れることはありません。

## 推奨サイズ（新しい写真を足すとき）

- 縦長カット … 4:5 または 3:4、横 1080px 以上
- 正方形カット … 1:1、1280px 以上
- ロゴ … 背景透過PNG、横 720px 以上
